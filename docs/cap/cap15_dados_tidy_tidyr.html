15  Dados tidy e transformação com tidyr

Organizando linhas, colunas e unidades de observação

Autor

Alexandre Nicolella

Data de Publicação

15 de setembro de 2026

No Capítulo 13, apresentamos os princípios de uma base tidy: uma variável em cada coluna, uma observação em cada linha e um valor em cada célula. Agora aprenderemos a reconhecer quando uma tabela não segue esses princípios e a reorganizá-la com o tidyr.

Nossa pergunta orientadora será:

Como organizar séries de indicadores econômicos para comparar sua evolução no tempo?

NotaObjetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

  • definir a unidade de observação de uma tabela;
  • distinguir apresentação visual e organização para análise;
  • reconhecer dados em formatos largo e longo;
  • utilizar pivot_longer() e pivot_wider();
  • separar informações reunidas em uma coluna;
  • unir colunas quando isso for necessário;
  • verificar se a transformação preservou as observações.

15.1 Começar pela unidade de observação

Antes de reorganizar uma tabela, precisamos completar a frase:

Cada linha representa __________.

Em wage1_core, cada linha representa uma pessoa. Em uma série econômica, cada linha pode representar um indicador em um período. Em uma base de domicílios, cada linha pode representar um domicílio ou um morador — e essa diferença altera toda a análise.

ImportanteTidy depende do que está sendo observado

Não existe organização correta sem definir a unidade de observação. Uma linha por pessoa, uma linha por domicílio e uma linha por mês descrevem estruturas diferentes.

15.2 Uma tabela feita para leitura

Vamos construir uma tabela pequena com valores anuais fictícios de três indicadores. Os números servem apenas para aprender a reorganização dos dados.

library(tidyverse)

indicadores_largos <- tibble(
  serie = c("inflacao_pct", "selic_pct", "pib_indice"),
  `2022` = c(5.8, 13.75, 100.0),
  `2023` = c(4.6, 11.75, 102.9),
  `2024` = c(4.8, 12.25, 106.3)
)

indicadores_largos
# A tibble: 3 x 4
  serie        `2022` `2023` `2024`
  <chr>         <dbl>  <dbl>  <dbl>
1 inflacao_pct    5.8    4.6    4.8
2 selic_pct      13.8   11.8   12.2
3 pib_indice    100    103.   106.

Essa tabela é fácil de ler: cada série ocupa uma linha e cada ano aparece em uma coluna. Para várias tarefas analíticas, porém, ela apresenta um problema: os nomes das colunas 2022, 2023 e 2024 são valores da variável ano, não três variáveis diferentes.

15.3 Formato largo e formato longo

No formato largo, uma mesma informação se espalha por várias colunas. No formato longo, os nomes dessas colunas tornam-se valores de uma variável.

Nenhum dos formatos é universalmente melhor. O formato adequado depende da tarefa. O formato longo costuma facilitar agrupamentos, gráficos e operações aplicadas a vários períodos.

15.4 Transformando colunas em linhas

pivot_longer() reúne as colunas dos anos em duas novas variáveis:

  • ano, contendo o nome da coluna original;
  • valor, contendo o número que estava na célula.
indicadores_longos <- indicadores_largos |>
  pivot_longer(
    cols = `2022`:`2024`,
    names_to = "ano",
    values_to = "valor"
  )

indicadores_longos
# A tibble: 9 x 3
  serie        ano   valor
  <chr>        <chr> <dbl>
1 inflacao_pct 2022    5.8
2 inflacao_pct 2023    4.6
3 inflacao_pct 2024    4.8
4 selic_pct    2022   13.8
5 selic_pct    2023   11.8
6 selic_pct    2024   12.2
7 pib_indice   2022  100  
8 pib_indice   2023  103. 
9 pib_indice   2024  106.

Agora cada linha representa uma combinação de série e ano. A unidade de observação ficou explícita.

Os nomes das colunas originais tornam-se texto por padrão. Como o ano será utilizado como número, podemos convertê-lo durante a própria transformação:

indicadores_longos <- indicadores_largos |>
  pivot_longer(
    cols = `2022`:`2024`,
    names_to = "ano",
    values_to = "valor",
    names_transform = list(ano = as.integer)
  )

glimpse(indicadores_longos)
Rows: 9
Columns: 3
$ serie <chr> "inflacao_pct", "inflacao_pct", "inflacao_pct", "selic_pct", "se~
$ ano   <int> 2022, 2023, 2024, 2022, 2023, 2024, 2022, 2023, 2024
$ valor <dbl> 5.80, 4.60, 4.80, 13.75, 11.75, 12.25, 100.00, 102.90, 106.30
DicaComo ler os argumentos

Em pivot_longer(), perguntamos:

  • quais colunas serão reunidas (cols)?
  • qual será o nome da coluna que receberá seus nomes (names_to)?
  • qual será o nome da coluna que receberá seus valores (values_to)?

15.5 Conferindo a transformação

A tabela larga tinha três séries e três anos. Portanto, esperamos obter (3 = 9) combinações:

nrow(indicadores_largos)
[1] 3
nrow(indicadores_longos)
[1] 9
indicadores_longos |>
  count(serie, ano) |>
  filter(n != 1)
# A tibble: 0 x 3
# i 3 variables: serie <chr>, ano <int>, n <int>

O último resultado deve ter zero linhas: cada combinação de série e ano aparece exatamente uma vez.

15.6 Transformando linhas em colunas

Podemos retornar ao formato largo com pivot_wider():

indicadores_largos_novamente <- indicadores_longos |>
  pivot_wider(
    names_from = ano,
    values_from = valor
  )

indicadores_largos_novamente
# A tibble: 3 x 4
  serie        `2022` `2023` `2024`
  <chr>         <dbl>  <dbl>  <dbl>
1 inflacao_pct    5.8    4.6    4.8
2 selic_pct      13.8   11.8   12.2
3 pib_indice    100    103.   106.

Em pivot_wider(), indicamos:

  • qual coluna fornecerá os novos nomes (names_from);
  • qual coluna fornecerá os valores (values_from).

Se mais de uma linha corresponder à mesma célula futura, o R não saberá qual valor utilizar. Isso geralmente revela duplicações ou uma unidade de observação ainda incompleta.

AvisoNão use pivot_wider() para esconder duplicações

Antes de alargar uma base, verifique se a combinação que identificará cada linha é única. Se houver várias observações para a mesma série e ano, investigue o motivo antes de agregá-las.

15.7 Quando várias informações ocupam uma coluna

Bases também podem reunir duas informações em um único texto. Considere códigos que combinam indicador e unidade:

series_codificadas <- tibble(
  codigo = c("inflacao_pct", "selic_pct", "pib_indice"),
  valor_2024 = c(4.8, 12.25, 106.3)
)

series_codificadas
# A tibble: 3 x 2
  codigo       valor_2024
  <chr>             <dbl>
1 inflacao_pct        4.8
2 selic_pct          12.2
3 pib_indice        106.

separate_wider_delim() divide o texto utilizando um delimitador. Neste exemplo, o sublinhado separa o indicador da unidade:

series_separadas <- series_codificadas |>
  separate_wider_delim(
    cols = codigo,
    delim = "_",
    names = c("indicador", "unidade")
  )

series_separadas
# A tibble: 3 x 3
  indicador unidade valor_2024
  <chr>     <chr>        <dbl>
1 inflacao  pct            4.8
2 selic     pct           12.2
3 pib       indice       106.

Essa operação somente é segura quando o delimitador possui um significado consistente. Se os próprios nomes dos indicadores contiverem sublinhados, precisaremos de outra regra.

15.8 Unindo colunas

Podemos realizar a operação inversa com unite(). Ela é útil quando duas ou mais colunas precisam formar um identificador ou rótulo:

series_reunidas <- series_separadas |>
  unite(
    col = codigo,
    indicador,
    unidade,
    sep = "_",
    remove = FALSE
  )

series_reunidas
# A tibble: 3 x 4
  codigo       indicador unidade valor_2024
  <chr>        <chr>     <chr>        <dbl>
1 inflacao_pct inflacao  pct            4.8
2 selic_pct    selic     pct           12.2
3 pib_indice   pib       indice       106.

Com remove = FALSE, preservamos as colunas originais para que seja possível conferir o resultado.

15.9 Uma pequena análise depois da organização

Depois de colocar os indicadores no formato longo, operações que se repetem para cada série ficam mais simples. Podemos calcular a variação entre o primeiro e o último valor disponível:

variacao_periodo <- indicadores_longos |>
  arrange(serie, ano) |>
  group_by(serie) |>
  summarise(
    primeiro_ano = first(ano),
    ultimo_ano = last(ano),
    primeiro_valor = first(valor),
    ultimo_valor = last(valor),
    variacao = ultimo_valor - primeiro_valor,
    .groups = "drop"
  )

variacao_periodo
# A tibble: 3 x 6
  serie        primeiro_ano ultimo_ano primeiro_valor ultimo_valor variacao
  <chr>               <int>      <int>          <dbl>        <dbl>    <dbl>
1 inflacao_pct         2022       2024            5.8          4.8     -1  
2 pib_indice           2022       2024          100          106.       6.3
3 selic_pct            2022       2024           13.8         12.2     -1.5

Os indicadores possuem unidades diferentes; por isso, suas variações não devem ser comparadas diretamente como se medissem a mesma coisa. A organização técnica não elimina a necessidade de interpretação econômica.

15.11 Pratique

Considere uma tabela com taxas de desemprego fictícias para três estados:

desemprego_largo <- tibble(
  uf = c("SP", "MG", "BA"),
  `2023_1` = c(8.5, 7.2, 13.0),
  `2023_2` = c(7.8, 6.8, 12.1)
)

desemprego_largo
# A tibble: 3 x 3
  uf    `2023_1` `2023_2`
  <chr>    <dbl>    <dbl>
1 SP         8.5      7.8
2 MG         7.2      6.8
3 BA        13       12.1

Transforme a tabela para que cada linha represente uma combinação de estado e trimestre. Crie as colunas periodo e taxa_desemprego. Depois, separe periodo nas colunas ano e trimestre.

DicaUma solução possível 
desemprego_longo <- desemprego_largo |>
  pivot_longer(
    cols = -uf,
    names_to = "periodo",
    values_to = "taxa_desemprego"
  ) |>
  separate_wider_delim(
    cols = periodo,
    delim = "_",
    names = c("ano", "trimestre")
  ) |>
  mutate(
    ano = as.integer(ano),
    trimestre = as.integer(trimestre)
  )
