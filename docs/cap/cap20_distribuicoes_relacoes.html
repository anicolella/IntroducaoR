20  Distribuições e relações entre variáveis

Da forma dos dados às associações observadas

Author

Alexandre Nicolella

Published

October 12, 2026

Uma média ou um coeficiente isolado não descreve toda a estrutura dos dados. Neste capítulo, combinaremos medidas e gráficos para examinar a forma das distribuições e as relações observadas entre variáveis.

Nossa pergunta orientadora será:

Como salários, escolaridade e experiência se distribuem e se relacionam na amostra?

NoteObjetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

  • examinar forma, centro e dispersão de uma distribuição;
  • reconhecer assimetria e possíveis valores extremos;
  • comparar distribuições condicionais entre grupos;
  • construir e interpretar tabelas cruzadas;
  • calcular covariância e correlação;
  • relacionar medidas numéricas e gráficos de dispersão;
  • distinguir associação observada de explicação causal.

20.1 Preparando a base

library(tidyverse)

wage1_core <- readRDS("dados/wage1_core.rds")

wage1_analise <- wage1_core |>

    sexo = factor(sexo, levels = c("Homem", "Mulher")),
    escolaridade = case_when(
      educ < 12 ~ "Menos de 12 anos",
      educ == 12 ~ "12 anos",

      .default = NA_character_

20.2 O que observar numa distribuição?

Uma análise inicial pode considerar quatro dimensões:

  1. centro: onde se concentram os valores;
  2. dispersão: quanto os valores variam;
  3. forma: simetria, caudas e concentrações;
  4. valores incomuns: observações distantes das demais.

20.3 Forma da distribuição salarial

Começamos combinando um histograma com linhas para média e mediana:

media_salario <- mean(wage1_analise$wage, na.rm = TRUE)
mediana_salario <- median(wage1_analise$wage, na.rm = TRUE)

ggplot(wage1_analise, aes(x = wage)) +
  geom_histogram(
    bins = 20,
    fill = "#7185CC",
    color = "white",
    alpha = 0.8
  ) +
  geom_vline(
    xintercept = media_salario,
    color = "#B45F4A",
    linewidth = 0.9,
    linetype = "dashed"
  ) +
  geom_vline(
    xintercept = mediana_salario,
    color = "#355E3B",
    linewidth = 0.9
  ) +
  labs(
    title = "Distribuição do salário por hora",
    subtitle = "Linha tracejada: média; linha contínua: mediana",
    x = "Salário por hora (US$)",
    y = "Frequência"
  ) +
  theme_minimal()

Quando a média está acima da mediana e a distribuição possui uma cauda com salários elevados, dizemos que há assimetria à direita ou assimetria positiva.

NoteAssimetria não é sinônimo de erro

Distribuições de renda e salários frequentemente apresentam cauda à direita. A assimetria pode ser uma característica econômica substantiva, e não um problema a ser removido.

20.4 Histograma e densidade

O histograma depende da escolha dos intervalos. A densidade produz uma curva suavizada:

ggplot(wage1_analise, aes(x = wage)) +
  geom_density(
    fill = "#7185CC",
    color = "#3F566F",
    alpha = 0.55
  ) +
  labs(
    title = "Densidade do salário por hora",
    x = "Salário por hora (US$)",
    y = "Densidade"
  ) +
  theme_minimal()

A suavização facilita perceber a forma geral, mas não deve ser confundida com uma distribuição teórica nem com uma contagem direta de pessoas.

20.5 Boxplot e possíveis valores extremos

O boxplot representa os quartis e utiliza o intervalo interquartil para sinalizar observações distantes:

  • limite inferior: (Q_1 - 1{,}5 IQR);
  • limite superior: (Q_3 + 1{,}5 IQR).
ggplot(wage1_analise, aes(y = wage)) +
  geom_boxplot(
    fill = "#7185CC",
    color = "#3F566F",
    alpha = 0.75,
    outlier.color = "#B45F4A"
  ) +
  labs(
    title = "Boxplot do salário por hora",
    x = NULL,
    y = "Salário por hora (US$)"
  ) +
  theme_minimal()

Podemos calcular os limites utilizados na regra:

q1_salario <- quantile(wage1_analise$wage, 0.25, na.rm = TRUE)
q3_salario <- quantile(wage1_analise$wage, 0.75, na.rm = TRUE)
iqr_salario <- IQR(wage1_analise$wage, na.rm = TRUE)

limite_inferior <- q1_salario - 1.5 * iqr_salario
limite_superior <- q3_salario + 1.5 * iqr_salario

20.6 Distribuições condicionais

Uma distribuição condicional descreve uma variável dentro de um grupo. Podemos comparar os salários de homens e mulheres:

ggplot(wage1_analise, aes(x = wage, fill = sexo)) +
  geom_density(alpha = 0.45) +
  labs(
    title = "Distribuição salarial condicionada ao sexo",

    fill = "Sexo"

  scale_fill_manual(values = c("Homem" = "#7185CC", "Mulher" = "#C2986F")) +

Perguntas úteis incluem:

  • existe alguma direção predominante?
  • a relação parece linear?
  • qual é a intensidade da dispersão?
  • existem grupos ou valores incomuns?
  • a variabilidade muda ao longo do eixo horizontal?

20.9 Covariância

A covariância indica se duas variáveis tendem a variar na mesma direção:

\[ s_{xy} = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{n-1} \]

cov(
  wage1_analise$educ,
  wage1_analise$wage,
  use = "complete.obs"
)
[1] 4.150864
  • covariância positiva: valores maiores de uma variável tendem a acompanhar valores maiores da outra;
  • covariância negativa: valores maiores de uma tendem a acompanhar valores menores da outra;
  • valor próximo de zero: ausência de uma associação linear clara.

Sua magnitude depende das unidades das duas variáveis, o que dificulta comparações entre pares diferentes.

20.10 Correlação

A correlação padroniza a covariância pelos desvios-padrão:

\[ r_{xy} = \frac{s_{xy}}{s_xs_y} \]

cor(
  wage1_analise$educ,
  wage1_analise$wage,
  use = "complete.obs"
)
[1] 0.4059033

O coeficiente varia entre -1 e 1:

  • próximo de 1: associação linear positiva forte;
  • próximo de -1: associação linear negativa forte;
  • próximo de 0: associação linear fraca.

Isso não significa que qualquer valor próximo de zero represente ausência de relação. Uma relação não linear pode apresentar correlação linear pequena.

20.11 Uma matriz de correlações

Podemos calcular correlações entre várias variáveis numéricas:

variaveis_numericas <- wage1_analise |>
  select(wage, educ, exper, tenure)

cor(
  variaveis_numericas,
  use = "complete.obs"
)
            wage        educ      exper      tenure
wage   1.0000000  0.40590333  0.1129034  0.34688957
educ   0.4059033  1.00000000 -0.2995418 -0.05617257
exper  0.1129034 -0.29954184  1.0000000  0.49929145

A matriz é simétrica e possui 1 na diagonal, pois cada variável está perfeitamente correlacionada consigo mesma.

WarningCorrelação não mede importância econômica

Um coeficiente alto não garante que a relação seja economicamente relevante, estável ou causal. Um coeficiente baixo também não prova que uma variável seja irrelevante para todas as perguntas.

20.12 Associação não é causalidade

Se escolaridade e salário estão positivamente associados, diferentes explicações permanecem possíveis:

  • escolaridade pode contribuir para produtividade e remuneração;
  • habilidades e condições familiares podem influenciar as duas variáveis;
  • pessoas podem selecionar trajetórias educacionais diferentes;
  • setores, ocupações e regiões podem alterar a relação;
  • erros de mensuração podem afetar os dados.

20.14 Pratique

Utilizando wage1_analise:

  1. examine a distribuição de tenure com histograma e boxplot;
  2. localize observações de permanência sinalizadas pela regra de (1{,}5 IQR);
  3. compare a distribuição de tenure entre homens e mulheres;
  4. construa um gráfico de dispersão entre exper e tenure;
  5. calcule sua covariância e correlação;
  6. escreva uma interpretação que diferencie associação e causalidade.
