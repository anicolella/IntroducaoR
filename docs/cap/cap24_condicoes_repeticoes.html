24  Condições, repetições e automação

Executando uma rotina para diferentes situações

Autor

Alexandre Nicolella

Data de Publicação

13 de outubro de 2026

Ao longo da apostila, repetimos operações como calcular médias, produzir tabelas e examinar diferentes variáveis. Quando o número de tarefas cresce, copiar e colar o mesmo código torna o trabalho demorado e aumenta a possibilidade de erros.

Neste capítulo, aprenderemos a instruir o R a:

  • tomar uma decisão;
  • repetir uma operação;
  • guardar os resultados;
  • automatizar uma pequena rotina de análise.
NotaObjetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

  • utilizar if e else para controlar a execução;
  • distinguir uma decisão única de uma operação vetorizada;
  • repetir comandos com for;
  • utilizar uma variável de controle;
  • guardar resultados produzidos em uma repetição;
  • combinar condições e repetições;
  • reconhecer quando um loop ajuda e quando uma solução vetorizada é mais simples.

24.2 Por que automatizar?

Suponha que desejemos calcular a média de quatro variáveis:

mean(wage1_core$wage)

mean(wage1_core$educ)
[1] 12.56274
mean(wage1_core$exper)
[1] 17.01711
mean(wage1_core$tenure)

O código funciona, mas a mesma estrutura foi escrita quatro vezes. Se tivéssemos cinquenta variáveis, a repetição manual seria pouco eficiente.

24.3 Uma decisão com if

if significa “se”. Ele executa um bloco somente quando uma condição é verdadeira.

media_salario <- mean(wage1_core$wage)

if (media_salario > 5) {
  print("O salário médio é superior a US$ 5 por hora.")
}
[1] "O salário médio é superior a US$ 5 por hora."

A estrutura é:

if (condicao) {
  codigo_executado_se_a_condicao_for_verdadeira
}

A condição precisa produzir um único valor TRUE ou FALSE:

media_salario > 5
[1] TRUE

24.4 Escolhendo entre duas alternativas

Com else, indicamos o que deve acontecer quando a condição for falsa:

limite <- 7

if (media_salario > limite) {
  mensagem <- "A média está acima do limite."
} else {
  mensagem <- "A média não está acima do limite."
}

mensagem
[1] "A média não está acima do limite."
Importanteelse deve acompanhar o fechamento do if

Escreva:

} else {

na mesma linha. Isso evita que o R interprete o comando como encerrado antes de encontrar else.

24.5 Mais de duas possibilidades

Podemos encadear decisões com else if:

if (media_salario < 5) {
  classificacao <- "Média inferior a US$ 5"
} else if (media_salario < 10) {
  classificacao <- "Média entre US$ 5 e US$ 10"
} else {
  classificacao <- "Média igual ou superior a US$ 10"
}

classificacao
[1] "Média entre US$ 5 e US$ 10"

As condições são avaliadas de cima para baixo. Assim que uma delas é verdadeira, as demais não são executadas.

24.6 if não é if_else()

if controla se um bloco de código será executado. Ele foi pensado para uma decisão única.

if_else() trabalha de forma vetorizada: avalia uma condição para cada elemento de uma coluna.

wage1_classificada <- wage1_core |>
  mutate(
    salario_acima_media = if_else(
      wage > media_salario,
      "Acima da média",
      "Até a média"
    )
  )

wage1_classificada |>
  count(salario_acima_media)
  salario_acima_media   n
1      Acima da média 201
2         Até a média 325
Necessidade Ferramenta
Executar ou não um bloco if
Escolher entre duas ações if e else
Classificar cada linha if_else()
Criar várias categorias case_when()

24.7 Repetindo uma operação com for

for percorre uma sequência. O exemplo abaixo preserva a ideia apresentada nas suas notas antigas: começamos com 3 e, a cada repetição, multiplicamos o valor anterior por 2.

x <- numeric(9)
x[1] <- 3

for (i in 2:9) {
  x[i] <- 2 * x[i - 1]
}

x
[1]   3   6  12  24  48  96 192 384 768

Na expressão:

for (i in 2:9)
  • i é a variável de controle;
  • 2:9 é a sequência percorrida;
  • o código entre chaves é executado para cada valor de i.

24.8 A importância da indentação

O R identifica o bloco pelas chaves, mas a indentação permite que uma pessoa reconheça sua estrutura:

for (i in 2:9) {
  x[i] <- 2 * x[i - 1]
}

O recuo mostra que a atribuição pertence ao for. Código bem indentado é mais fácil de ler, revisar e corrigir.

24.10 Guardando os resultados

Antes do loop, criamos um vetor vazio com o tamanho necessário:

medias <- numeric(length(variaveis))

for (i in seq_along(variaveis)) {
  nome_variavel <- variaveis[i]

  medias[i] <- mean(
    wage1_core[[nome_variavel]],
    na.rm = TRUE
  )
}

medias
[1]  5.896103 12.562738 17.017110  5.104563

seq_along(variaveis) cria uma sequência segura de posições: 1, 2, 3 e 4.

Combinamos os nomes e resultados em uma tabela:

tabela_medias <- tibble(
  variavel = variaveis,
  media = medias
)

tabela_medias
# A tibble: 4 × 2
  variavel media
  <chr>    <dbl>
1 wage      5.90
2 educ     12.6 
3 exper    17.0 
4 tenure    5.10
DicaPrepare o objeto antes de iniciar o loop

Guardar resultados é preferível a apenas imprimi-los. Quando sabemos o tamanho da saída, preparar o vetor antes do loop também evita ampliar o objeto a cada repetição.

24.11 Automatizando várias medidas

Podemos armazenar mais de uma estatística em cada repetição:

resumo_variaveis <- tibble(
  variavel = character(),
  media = double(),
  mediana = double(),
  desvio_padrao = double()
)

for (variavel in variaveis) {
  valores <- wage1_core[[variavel]]

  nova_linha <- tibble(
    variavel = variavel,
    media = mean(valores, na.rm = TRUE),
    mediana = median(valores, na.rm = TRUE),
    desvio_padrao = sd(valores, na.rm = TRUE)
  )

  resumo_variaveis <- bind_rows(
    resumo_variaveis,
    nova_linha
  )
}

24.12 Combinando if e for

Suponha que uma lista contenha também uma variável categórica:

wage1_tipos <- wage1_core |>
  mutate(
    sexo = if_else(female == 1, "Mulher", "Homem")
  )

variaveis_mistas <- c(
  "wage",
  "educ",
  "exper",
  "tenure",
  "sexo"
)

Antes de calcular a média, verificamos se a coluna é numérica:

for (variavel in variaveis_mistas) {
  valores <- wage1_tipos[[variavel]]

  if (is.numeric(valores)) {
    resultado <- mean(valores, na.rm = TRUE)
    print(paste(variavel, ": média =", round(resultado, 2)))
  } else {
    print(paste(variavel, ": variável não numérica"))
  }
}
[1] "wage : média = 5.9"
[1] "educ : média = 12.56"
[1] "exper : média = 17.02"
[1] "tenure : média = 5.1"
[1] "sexo : variável não numérica"

O if decide o que fazer em cada passagem do for.

24.13 Quando não precisamos de um loop?

Muitas funções do R já são vetorizadas. Para multiplicar todos os salários por 100, não precisamos percorrer linha por linha:

salario_centavos <- wage1_core$wage * 100

head(salario_centavos)
[1] 310 324 300 600 530 875

Da mesma forma, summarise(across()) calcula medidas para várias colunas:

wage1_core |>
  summarise(
    across(
      all_of(variaveis),
      list(
        media = ~ mean(.x, na.rm = TRUE),
        mediana = ~ median(.x, na.rm = TRUE),
        dp = ~ sd(.x, na.rm = TRUE)
      )
    )
  )
  wage_media wage_mediana  wage_dp educ_media educ_mediana  educ_dp exper_media
1   5.896103         4.65 3.693086   12.56274           12 2.769022    17.01711
  exper_mediana exper_dp tenure_media tenure_mediana tenure_dp
1          13.5 13.57216     5.104563              2  7.224462

O loop continua útil quando:

  • a rotina possui várias etapas;
  • cada repetição produz objetos diferentes;
  • precisamos executar decisões dentro da repetição;
  • não existe uma operação vetorizada simples;
  • a forma explícita ajuda a compreender o algoritmo.
NotaEntenda mais: e o while?

while repete um bloco enquanto uma condição for verdadeira:

valor <- 1

while (valor < 100) {
  valor <- valor * 2
}

valor
[1] 128

Ele é útil quando não sabemos previamente quantas repetições serão necessárias. Precisamos garantir que a condição se torne falsa; caso contrário, o loop continuará indefinidamente.

24.15 Pratique

  1. Crie um if que informe se a média de educ é maior que 12.
  2. Use if, else if e else para classificar a média de exper.
  3. Crie um vetor com wage, educ e tenure.
  4. Utilize for para calcular o valor mínimo de cada variável.
  5. Guarde os resultados em uma tabela.
  6. Inclua sexo na lista e use if para evitar calcular sua média.

variaveis_pratica <- c("wage", "educ", "tenure")
minimos <- numeric(length(variaveis_pratica))

for (i in seq_along(variaveis_pratica)) {
  variavel <- variaveis_pratica[i]
  minimos[i] <- min(
    wage1_core[[variavel]],
    na.rm = TRUE
  )
}
